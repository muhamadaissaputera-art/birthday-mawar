# Website Ulang Tahun Mawarni Agustin ♡

Website hadiah ulang tahun untuk Mawarni Agustin, 18 Agustus 2026.

## Isi folder
- `index.html` halaman utama
- `style.css` desain dan animasi
- `script.js` interaksi, confetti, efek suara kecil, dan galeri
- `photos/` 10 foto dari ZIP yang dikirim
- `qr.html` pembuat QR Code setelah website mendapat URL

## Cara mencoba
Buka `index.html` di browser. Website tidak membutuhkan PHP atau database.

## Cara membuatnya bisa dibuka dari QR Code
1. Upload seluruh isi folder ini ke layanan hosting statis seperti GitHub Pages, Netlify, atau Vercel.
2. Setelah mendapat URL website, buat QR Code dari URL tersebut.
3. Buka `qr.html`, masukkan URL website, lalu buat QR Code.
4. Cetak QR Code di kartu/hadiah.

## Catatan
Tombol suara menggunakan Web Audio bawaan browser untuk membuat bunyi kecil yang lembut. Jika ingin lagu tertentu, tambahkan file audio sendiri dan ubah `script.js`.
